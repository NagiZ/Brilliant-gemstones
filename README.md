# 璀璨宝石（Splendor）在线 Web 版

这是一个零外部依赖的《璀璨宝石》在线联机实现，支持 2 至 4 名玩家实时对战。

## 运行方式

需要 Node.js 18 或更高版本。

```powershell
npm start
```

然后打开：

```text
http://localhost:3000
```

创建房间后会得到一个房间码，把房间码分享给其他玩家，其他玩家选择“加入房间”即可联机。

## 技术结构

- `server.js`：Node.js 内置 HTTP 服务、房间管理、动作接口、SSE 实时推送。
- `lib/game.js`：璀璨宝石规则模型，包括拿取宝石、购买/保留卡牌、黄金万能支付、贵族来访、最后一轮与胜负判定。
- `public/`：原生 HTML/CSS/JavaScript 前端，无构建步骤。

## 已实现的规则

- 2 人、3 人、4 人局的宝石数量分别为 4、5、7，黄金始终为 5。
- 贵族数量为玩家数 + 1。
- 每回合可拿取 3 枚不同色宝石、2 枚同色宝石、保留卡牌或购买卡牌。
- 黄金作为保留卡牌奖励和购买万能支付。
- 手牌宝石上限为 10，超出后需要归还。
- 保留卡牌对其他玩家隐藏，最多保留 3 张。
- 购买发展卡获得声望和永久宝石加成。
- 达到 15 分后进入最后一轮，所有玩家回合数一致。
- 终局平分时，发展卡更少者获胜。
