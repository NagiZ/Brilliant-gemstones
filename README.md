# 棱境商会

一款 2 至 4 人的原创联机宝石桌游。牌面和宝石由浏览器直接绘制，可以在桌面和手机上游玩。

用 Node.js 18 或更高版本，在项目目录运行 `npm start`，再打开 [本地页面](http://localhost:3000)。可用 `PORT` 环境变量设置监听端口。所有玩家需要访问同一个服务实例。房主创建房间后，可以复制邀请链接，好友也可以手动输入房间码加入。

每回合选择取宝石、保留卡牌、制作作品或交付商会委托。作品提供永久折扣，委托按已完成的作品颜色计数，交付时不消耗作品。有人达到 16 分时打完本轮，最高分获胜，同分共享胜利。详细规则见牌桌底部的「玩法」。

拿取时可选择 3 枚不同色宝石，库存不足 3 种则取现有的每种各 1 枚。也可从至少有 4 枚的同色堆取 2 枚。每局共有 5 枚金砂。每人最多保留 3 张牌，回合结束时最多持有 10 枚筹码（含金砂）。确认拿取前会提示预计需要归还的数量。回合提示下方可展开查看本局所有玩家的操作。

聊天仅对同房间成员开放，开局前、进行中和结算后都可使用。房间保留最近 100 条聊天消息以便重连。房间、进度和消息都存放在服务内存里，重启后清空。如果使用 Nginx 代理，请为 SSE 路由关闭缓冲，并保持单实例运行。

大厅和房间顶部的音乐按钮可以播放或暂停原创配乐《工坊夜曲》。配乐默认关闭，开启后进入房间会继续播放。
